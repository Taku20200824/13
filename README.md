# 13 Хөзөр

4 тоглогчтой 13 хөзрийн тоглоомын browser хувилбар.

## Яаж ажиллуулах вэ

`index.html` файлыг browser дээр нээхэд шууд ажиллана.

## Боломжууд

- 1 хүн 3 bot-той тоглоно
- 52 хөзрийг 4 тоглогчид 13-аар тараана
- 3♣-тай тоглогч эхэлнэ
- Single, pair, triple, straight, 4-kind, consecutive pairs шалгана
- Пасс, тавих, шинэ тоглоом, гар эрэмбэлэх control-той
